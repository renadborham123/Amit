# Task-8

This folder contains the NumPy programming assignment shown in the attached
image:

1. `array_factory` creates arrays in `zeros`, `ones`, `full`, and `identity`
   modes.
2. `secure_reshape_and_stack` converts datasets to NumPy arrays, reshapes the
   first dataset, and vertically stacks both matrices with clear validation
   errors.

## Run

From the repository root:

```bash
python Task-8/main.py
```

NumPy is required (`pip install numpy`).
