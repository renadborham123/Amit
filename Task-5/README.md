# Task-5

Task-5 converts the five Task-4 function exercises into an object-oriented
design. Each class stores its inputs in `__init__`, exposes a method for the
main operation, and includes class and method docstrings.

## Classes

- `MultiplicationTable`: generates the table for a number.
- `TwinPrimeFinder`: finds twin-prime pairs below a limit.
- `PrimeFactorizer`: returns repeated prime factors.
- `DecimalToBinary`: converts a decimal integer to binary.
- `PerfectNumberFinder`: finds perfect numbers in an inclusive range.

## Run

From the repository root:

```bash
python Task-5/main.py
```

The examples match Task-4: table for `9`, factors of `56`, binary for `11`,
and perfect numbers from `0` through `100`.
